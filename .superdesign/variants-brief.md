# Ten structurally different foosball tracker directions
User requests ten clickable alternative artifacts/designs for home/rivalries, rivalry dashboard, and live scoring. They explicitly reject dramatic text, big marketing hero, slogans. UI should be compact for friends. Retain foosball theme and all real controls. Each branch should include a compact working preview nav to switch its three sample views using inline JS. Sample players Josh and Brooks, H2H 4–2, recent 10–8, live 3–2. California time labels. Each style must use different structural organization, not just colors.

Allowed design systems by requested branch:
1 club: navy #111d24/#20323c, blue #83c8f0/orange #f3b07e, sans, rounded compact rivalry cards, mirrored stat bars, paired rung columns.
2 paper: white #fff, ink #18232b, grey #e6e9ec, blue #2563a6/orange #a84c1c, serif headings/system body; horizontal rivalry list, semantic stat tables, row-based scoring.
3 pitch: green #123d31/#205340, white #eef7ed, sky #a9dff4/gold #ffd088, condensed athletic sans; table-shaped rivalry diagrams, rung stats on field positions, scorer on illustrated pitch.
4 mono: black #101010/white #fff/gray #ddd, strong sans/mono scores; dense rivalry table, numeric stat matrix, 2x2 rung grid per player, squared borders.
5 arcade: dark purple #17132b/#282044, cyan #72f5e2/pink #f5a0dc, monospace/rounded sans; opposing duel panels, stacked goal distributions, large 2x2 scoring pads.
6 clay: cream #f5ead9, brown #3e2d21/#e3cdb0, teal #28696a/rust #a34527, Georgia headings/sans body; receipt/ticket rivalry cards, tally-dot stat displays, compact paired scorer.
7 blueprint: deep blue #102c50/#173f68, pale #d3e7f7, sky #81ceff/amber #ffd08a, mono/sans; structured rivalry matrix, technical stat tables, fine line wireframe scoring rows.
8 coral: white #fff9f7, coral #c95041/teal #237b7e, dark #293339; soft rounded sans; compact square rivalry tiles, donut stat summaries with readable legends, rounded scoring grid.
9 stadium: charcoal #151b25/#222b39, white #f4f5f7, blue #8ebcff/red #ff9f9f, bold condensed sports type; result-led broadcast strips, horizontal stats ticker + stacked bars, horizontal scoreboard and scoring control strips.
10 forest: pale #eef1e8, forest #294b3f, moss #567c45/ochre #966526, calm system sans; spacious divided lists, side-by-side stat bars, simple scoring rows.

Global: 44px controls, readable contrast, responsive phone layouts, no sidebar clutter, no promotional panels. Use ONLY fonts/colors/spacing/component styles of the named branch system. Do not introduce unrelated fonts/colors/styles. Preserve clarity over decorative details.

## Subsequent implementation feedback

All ten designs share black/white table sides. Score digits are unboxed. Layouts vary in actual markup for collections, summaries, distributions, scoreboards, and rung controls. Clay embeds recent games inside each rivalry ticket. The header includes a muted IXL League mark. The momentum chart is compact and names the player above/below its tied baseline. Original generated previews predate this feedback; use the application's header to compare current designs.

## Final selection
Clay selected by the user. Shared app is fixed to Clay, with Mono player-stat tables and recent games inside each rivalry ticket. Other variants are retained only as design exploration source.
