# Recoverable deletion implementation plan

Goal: /backlog stores removed games and rivalries, restores original records, and offers confirmed permanent deletion. Undo the unshipped auto-capitalization first.

Approach: nullable deleted_at flags on original foos_games and foos_rivalries. No copying to archive tables (which risks losing links or newly added columns). Parent deletion hides all children implicitly; separately deleted children remain deleted on parent restore. Keep roster uniqueness across archived rows and route duplicate creations to backlog. Existing load RPC excludes all archived content so old clients also receive active-only statistics.

- [x] Persistence: soft delete and restore with parent-first locking, expected revisions/snapshots, and archived-only purge; guard both save RPC versions against deleted records. Preserve goals, lineups, swap times, IDs, and timestamps. No original data rewriting.
- [x] Local storage parity and active-only reads; archived game slot no longer blocks a new live game. Restore conflicts surface without mutating records. Restored live games keep original start time.
- [x] UI: manually entered /backlog route with no navigation link, deleted rivalries grouped with game details, standalone games, Undo and confirmed permanent delete. Active parent required before child management. Pacific timestamps, compact responsive rows, no browser tests.
- [x] Refresh normal state after restore/purge; refresh backlog on polling/focus and actions. No success shown for failed requests; stale confirmations rejected.
- [x] Verify local Postgres transactions (including anon calls), restored record equality, archived isolation, rollback and stale operations; integration/unit tests for derived stats and UI; build. Apply additive schema to confirmed project, verify without altering real games. No frontend production release unless requested.

Scope clarification: individual soft deletion is for finished games only. Discarding a live game remains permanent. Rivalry deletion preserves every child, including any unfinished game. Previously permanently deleted records cannot be recovered.
