# Player scouting notes

Approved direction: one compact, dynamically selected scouting note inside each player's Overview. A themed icon, title and short claim open a centered evidence dialog with game links. Preserve the existing clay palette, typography and phone carousel. No browser testing or deployment.

Use a deterministic library of calculated patterns rather than AI-authored claims or hard-coded player facts. Rank evidence, effect size, personality and modest recency; diversify similarly strong choices. Keep a locally remembered note unless a challenger beats it clearly. Always regenerate its text and evidence from current data; remove ineligible notes immediately.

Candidates cover team chemistry, rematches, opening goalie goals, closing rungs, special-shot habits, reactions and memorable outings. Team results belong to both members; personal sequences require known attribution from each goal's lineup snapshot. Legacy split goals cannot support exact personal facts. Exclude live/archived games and archived parents. New scorers get a concrete outing; profiles without goals get no invented claim.

Alternatives considered: static manually picked blurbs would become stale; open-ended AI generation risks unsupported claims. Calculated templates give clear evidence and automatic updates without a new service or database writes.

Visual: compact sage/gold/clay note strip, left icon and text, right chevron; wrapping text, no fixed height or clipped claims. Evidence list scrolls within a centered dialog. Existing theme variables and fonts stay in place.
